# 透明背景动画

每个已完成动作的透明动画保存在对应动作目录的：

```text
Preview/透明背景/
```

导出格式为无损动画 WebP，保留完整 Alpha 透明通道。

| 动作 | 动画特性 |
| --- | --- |
| 从左向右走 | 1280×720 透明画布，角色从最左侧走到最右侧 |
| 原地转棍 | 跳跃转正面、转两圈棍并回到侧面 |
| 坐下打坐 | 打坐循环，想法泡泡中的约修亚轻微浮动 |
| 暂停过渡 | 从站立/走路过渡到坐下打坐 |
| 继续过渡 | 从打坐跳起并回到走路姿态 |
| 被鼠标提起 | 气呼呼挣扎循环 |
| 差点摔倒又站稳 | 走路中踉跄、用棍撑地并恢复 |
