# 走路中差点摔倒又站稳

从左向右走途中低频随机触发的插入动作。

动作顺序：

1. 从正式走路循环的 `01-right-foot-contact.png` 进入。
2. 右脚尖绊住，身体开始前倾。
3. 重心越过支撑脚，后脚慌乱抬起，左手向前扑出。
4. 人物自己的右手将唯一一根棍子斜撑到前方地面。
5. 棍尖落地后，右肘和双膝弯曲，身体下沉吸收冲量。
6. 借棍子的支撑反弹，按相反顺序恢复重心。
7. 最后一帧原封不动复用 `01-right-foot-contact.png`，随后可直接继续从左向右走。

规则：

- 动作期间暂停水平位移，站稳后继续向右。
- 棍子始终由人物自己的右手握持；深蓝护肩仍只在人物自己的左肩。
- 无嘴，惊讶感只由眼睛、身体倾斜和双马尾惯性表达。
- `Sources/` 保留四张生成关键帧；恢复阶段反向复用已审核的姿势，避免人物比例和左右手漂移。
